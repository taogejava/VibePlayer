# 知乎回答话术

## 适用问题：「有什么好用的 macOS 媒体播放器」/ 「Electron 桌面开发案例」

推荐一个我自己做的开源播放器 **VibePlayer**，Electron 实现，主要功能：

- 本地音乐/视频播放，支持专辑/歌手分类
- 内嵌 B 站播放器（WebContentsView 方案，体验接近原生）
- WebDAV / AList 网盘直接播放
- URL 直链播放
- 基于 iTunes API 的在线音乐搜索（免版权）
- 本地歌词 + 在线歌词搜索（LRC 同步滚动）

刚发了 v1.3.3，更新了全套 Logo 设计。

地址：https://github.com/taogejava/VibePlayer
